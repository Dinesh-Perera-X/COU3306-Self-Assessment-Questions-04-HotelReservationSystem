# COU3306 - Data Structures and Algorithms
## Self-Assessment Questions 04 (SAQs 04): Hotel Reservation System

### 📌 Overview
This repository contains an Object-Oriented Java program for managing hotel room reservations. Developed as part of the **COU3306 - Data Structures and Algorithms** course at **The Open University of Sri Lanka (OUSL)**.

### 🛠️ Domain Models & Classes
- **`Guest`**: Stores guest information (`guestId`, `guestName`, `contactNumber`) and displays guest details.
- **`Room`**: Stores room information (`roomNumber`, `roomType`, `pricePerNight`) and calculates duration charges.
- **`Reservation`**: Aggregates `Guest` and `Room` entities to calculate total billing charges based on stay duration.
- **`Main`**: Main execution class testing guest creations, room assignments, and reservation calculations.

### 📂 File Structure
- `src/Guest.java`
- `src/Room.java`
- `src/Reservation.java`
